# 교사 모임 추가 업데이트

이번 파일은 2026-09-28.3 버전입니다. 앞서 적용한 자동 동선·중복 이름·인원 삭제·위치 공유·공지 삭제 기능도 모두 포함합니다.

1. 기존 구글시트 → **확장 프로그램 → Apps Script**를 엽니다.
2. **Code.gs 전체를 RobotlandSheets-교사모임.gs의 전체 내용으로 교체**하고 저장합니다.
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 누릅니다.
4. 로봇랜드 앱을 새로고침합니다.

기존 코드·시트 데이터·연결 비밀키·웹앱 주소는 유지됩니다. 처음 설정을 다시 실행할 필요는 없습니다. 교사 대화용 StaffMessages 탭은 첫 메시지를 보낼 때 자동으로 생성됩니다.

## 선생님 입장

앱 **우리 반 → 선생님 · 교사 모임 입장**에서 공용 교사 입장코드와 이름을 입력합니다. 교사 입장코드는 기존 **교사용 개설코드**와 같습니다. 구글시트의 **로봇랜드 → 교사용 개설코드 확인**에서 확인할 수 있습니다.

반을 먼저 만들 필요가 없습니다. 교사 모임에서 **반·조 현황 → 이 반으로 입장**을 누르면 해당 반을 바로 관리합니다. 반마다 다른 코드를 입력할 필요는 없습니다. 해당 반의 **교사 모임** 탭으로 돌아오면 다른 반을 선택할 수 있습니다.

이미 받은 반별 선생님 참여코드로 로그인해도 교사 모임이 표시됩니다. 컴퓨터와 휴대폰은 각각 교사로 로그인해 함께 이용할 수 있습니다.

## 반·조 정보와 대화

- 반별 등록 학생 수와 조 목록, 조 인원, 마지막 위치 표시, 공유 동선을 확인합니다. 등록 학생 수는 앱의 접속·조 등록 기록을 기준으로 하므로 실제 출석 인원과 다를 수 있습니다.
- **동선·위치 보기**에서 안내도와 방문 순서를 확인합니다.
- **반 정보 공유 / 조 정보 공유** → 내용을 적고 **교사 모임에 보내기**를 누르면, 전송 시점의 정보를 선생님들에게 공유합니다. 이후 동선·위치가 바뀌어도 이전 메시지의 정보는 그대로 남습니다.
- **새 반 만들기**에서 반 이름을 입력하면 학생 참여코드가 발급됩니다. 교사 인증 후에는 개설코드를 다시 묻지 않습니다.
- 학생에게는 교사 모임이 보이지 않으며, 서버에서도 접근을 거부합니다. 인증된 교사는 같은 저장소의 운영 중인 모든 반을 열람·관리할 수 있습니다. 교사 입장코드는 선생님에게만 공유하세요.
- 학생 반의 명단·대화·조 기능은 계속 반별로 분리됩니다. 학생 이름·기기 정보·참여코드는 교사 모임의 공통 현황에 포함하지 않습니다.
- 교사 모임을 열어두면 20초마다 갱신합니다. 앱을 닫은 상태의 푸시 알림은 아직 지원하지 않습니다.
