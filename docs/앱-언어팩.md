# 앱 전체 언어팩

상단의 언어 목록에서 **한국어 / English / 中文 / Русский**를 선택합니다. 선택한 언어는 이 기기에 저장됩니다.

## 적용되는 화면

- 지도 메뉴, 시설 이름과 종류, 화장실 위치
- 개인·조 동선, 대기·이용시간, 점심·퇴장 집합 안내
- 학생·교사 입장, 반 설정, 조 관리, 백업과 재입장
- 반 채팅의 메뉴·상태, 교사 모임과 반·조 현황
- QR 공유, 설치 안내, 알림 설정, 서버 오류 안내
- 기기에서 표시하는 푸시 안내와 신규 설치용 앱 이름

네 언어에 같은 **732개 화면 문구**와 시설 이름을 포함했습니다. 외부 번역 API는 사용하지 않습니다.

## 언어 변경 시

앱 화면을 다시 읽되 로그인은 유지합니다. 개인·조 동선, 조 동선의 변경 기준 버전, 작성 중인 반 채팅·교사 대화, 열려 있던 주요 화면을 복원합니다. 초안은 같은 반·기기·역할일 때만 복원합니다.

앱 언어를 바꾸면 선택형 채팅의 언어도 맞춥니다. 선택형 채팅 창에서만 다른 언어를 고르는 것도 가능합니다. 조합한 외국어 문장은 기존과 같이 **한국어와 선택 언어를 함께** 입력창에 넣고, 사용자가 보내기 버튼을 눌러 전송합니다.

사용자가 입력한 이름, 반·조 이름, 공지와 대화 내용은 자동 번역하지 않습니다. 공식 지도 이미지 안에 이미 그려진 글자는 원본 그대로입니다. 이미지 위 시설 표시와 시설 목록은 선택 언어로 표시합니다. 시설 번역명은 이해를 돕는 표기입니다.

한 번 정상 접속하여 오프라인 저장을 마치면 네 언어팩을 오프라인에서도 사용할 수 있습니다. 반·조 동기화와 메시지 전송은 기존처럼 인터넷 연결이 필요합니다.

## 문구 수정

- `public/app-ko.js`, `app-en.js`, `app-zh.js`, `app-ru.js`: 앱 화면 문구, 시설명, 푸시 안내
- `public/i18n.js`: 문구 선택, 언어 설정, 초안·화면 복원
- `public/i18n-data.js`: 시설 이름 연결
- `public/i18n.css`: 긴 번역 문구의 휴대폰 화면 처리
- `public/chat-*.json`: 선택형 채팅의 문장과 드롭다운
- `public/manifest-*.webmanifest`: 언어별 설치 정보

앱 문구는 한국어 원문을 키로 사용합니다. 새 문구는 네 팩에 같은 키를 추가하세요. `⟦0⟧`, `⟦1⟧` 같은 번호는 이름·숫자가 들어갈 자리이므로 삭제하거나 번호를 바꾸지 마세요. 각 언어의 어순에 맞게 위치를 바꿀 수는 있습니다.

동적인 화면은 `RobotlandI18n.text(원문, [값들])`를 사용합니다. 사용자 입력은 번역 대상에 넣지 않고 기존처럼 HTML 이스케이프한 뒤 자리표시자로 넘깁니다. 서버 응답에서는 오류 필드만 번역합니다.

## 확인

- `npm test`: 기존 기능과 언어팩 키·자리표시자·시설명, 사용자 내용 보존, 오류·푸시 번역 검사
- `npm run build`: 언어팩과 설치 정보를 포함한 배포 파일 생성
- `npm run dev`로 앱을 실행한 뒤 `npm run test:languages`: 실제 브라우저로 네 언어 전환, 작은 화면, 초안·동선·공유 버전 보존, 오프라인 동작 검사

브라우저 검사는 Playwright와 Edge가 있는 환경에서 실행합니다. 별도 설치 위치를 사용하는 경우 `PLAYWRIGHT_MODULE`에 Playwright 모듈 경로를 지정할 수 있습니다. 다른 Chromium 브라우저는 `BROWSER_CHANNEL`로 지정합니다. 테스트는 API를 가짜 응답으로 대체하여 실제 반·학생 정보를 변경하지 않습니다.

이번 변경에는 Apps Script 교체가 필요하지 않습니다. GitHub main 브랜치에 반영하면 기존 Netlify 자동 배포를 통해 운영 사이트에 적용됩니다.
