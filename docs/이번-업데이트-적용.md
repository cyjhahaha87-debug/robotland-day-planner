# 구글 Apps Script 업데이트

웹앱 화면은 Netlify 배포로 갱신됩니다. 학생 이름 중복 방지·교사 인원 삭제·조별 위치 공유를 사용하려면 아래 작업을 한 번 해주세요.

1. 기존 구글시트를 열고 **확장 프로그램 → Apps Script**를 누릅니다.
2. 기존 `Code.gs`의 내용을 전체 선택하고, 함께 제공한 `RobotlandSheets.gs`의 전체 내용으로 교체한 뒤 저장합니다.
3. 오른쪽 위 **배포 → 배포 관리**로 들어갑니다.
4. 현재 웹앱 배포의 **연필(수정)**을 누릅니다.
5. 버전을 **새 버전**으로 선택하고 **배포**를 누릅니다.
6. 앱을 다시 열거나 새로고침합니다.

기존 시트 데이터, 참여코드, 연결 비밀키와 웹앱 주소를 계속 사용합니다. ‘처음 설정’을 다시 실행할 필요는 없습니다. 위치 저장용 `GroupLocations` 탭은 첫 위치 표시 때 자동으로 생깁니다.

## 사용 방법

- 학생은 시설만 순서대로 선택합니다. 점심 전 이용을 마치고 12시까지 다목적홀에 도착하기 어려우면 점심을 먼저 넣고 남은 시설을 12:40 이후로 배치합니다.
- 13시 퇴장 집합에 늦는 일정은 늦는 시간을 표시합니다. 시설을 줄이거나 대기시간을 조정하세요.
- 위치: 반 입장 → 조 가입 → 지도 → **우리 조 위치 찍기** → 지도에서 위치 선택 → **여기에 표시**. GPS 자동 추적은 아닙니다.
- 인원 삭제: **우리 반 → 조 · 동선 공유 → 선생님 · 인원과 조 관리 → 인원 삭제**. 그 기기의 로그인과 조 소속을 해제하며, 반 코드로 다시 입장할 수 있습니다. 과거 메시지를 지우는 기능은 아닙니다.
- 교사 휴대폰 접속: 컴퓨터의 **우리 반 → 반 설정**에서 **선생님 참여코드**를 확인하고 휴대폰에서 같은 코드와 이름으로 입장합니다. 컴퓨터와 휴대폰 접속을 함께 유지합니다.
- 학생 동명이인은 번호를 붙여 구분하세요. 선생님은 여러 기기 접속을 위해 같은 이름이 허용되며, 인원 목록에 기기 구분이 표시됩니다.
- 같은 브라우저의 시크릿 창들은 로그인 저장소를 공유합니다. 두 학생 테스트는 일반 창+시크릿 창, 서로 다른 브라우저 또는 서로 다른 휴대폰을 쓰세요.
- 일반 창에서 같은 기기로 다시 열면 로그인과 조 소속이 유지됩니다. 모든 시크릿 창을 닫으면 임시 기기 정보가 사라지므로 재입장이 필요하며, 같은 이름의 기존 기록은 선생님이 삭제할 수 있습니다.
- 홈 화면 추가는 앱 실행 바로가기를 만듭니다. 현재 앱을 닫은 상태의 푸시 알림은 지원하지 않습니다.

- 공지 삭제: 교사 로그인 후 **우리 반 → 반 공지 · 대화 → 공지 아래 공지 삭제**. 학생 화면도 다음 갱신 때 반영됩니다. 다른 반의 공지는 삭제할 수 없습니다.
- 공용 교사용 개설코드로 여러 선생님이 각자 반을 만들 수 있습니다. 반마다 생성되는 학생·선생님 참여코드는 서로 다릅니다.
