# 조 초대 QR 추가 업데이트

공개 앱: https://robotland-trip.netlify.app/

위치 확인 창의 맥동 효과와 앱 주소 QR 공유는 사이트 새로고침 후 사용할 수 있습니다. **반·조 동시 입장 QR**을 쓰려면 저장소의 Apps Script도 아래와 같이 업데이트해 주세요.

1. 기존 구글시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. **Code.gs 전체 내용**을 `RobotlandSheets-조초대.gs` 파일의 전체 내용으로 교체하고 저장합니다.
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 누릅니다.
4. 로봇랜드 앱을 새로고침합니다.

이번 저장소 버전은 **2026-09-28.4**입니다. 기존 교사 모임·위치 공유·공지 삭제 등도 모두 포함합니다. 처음 설정을 다시 실행하거나 새 배포 주소를 만들 필요는 없습니다. 기존 코드, 데이터, 연결 비밀키, 웹앱 주소를 그대로 사용합니다. 초대 정보를 저장하는 GroupInvites 탭은 처음 초대를 만들 때 자동 생성됩니다.

## 조 초대 사용법

1. 조장이 반에 입장하고 조를 만듭니다. 이미 만든 조에 들어가 있어도 됩니다.
2. 앱 위쪽 **QR 공유**(큰 화면에서는 **친구에게 공유**) → **우리 조 초대**를 누릅니다.
3. 친구가 카메라로 QR을 찍고 **자기 이름 → 반·조 함께 입장**을 누르면 해당 반과 조에 입장합니다. 반 코드와 조 코드를 따로 입력할 필요가 없습니다.
4. **주소 복사 / 휴대폰 공유 / QR 저장**으로도 전달할 수 있습니다. 휴대폰 공유 메뉴는 브라우저가 지원할 때 표시됩니다.

조장만의 별도 권한 없이 같은 조의 학생 누구나 자기 조 초대 QR을 만들 수 있습니다. **앱 주소 공유**는 일반 접속 QR이며, 이 QR로 들어간 친구는 평소처럼 반 코드를 입력합니다.

초대는 발급 후 최대 24시간 동안 유효합니다. 반 참여 기간이 먼저 끝나면 그때 만료됩니다. 조를 해산하거나 학생 입장을 중지하면 기존 초대는 사용할 수 없습니다. 새 QR을 만들어도 앞서 만든 유효한 QR은 만료 시점까지 사용할 수 있습니다.

초대로 입장하는 사람은 항상 학생 권한입니다. QR에 교사 코드나 반 코드를 넣지 않습니다. QR을 가진 사람은 해당 반·조에 입장할 수 있으므로 같은 반 친구에게 공유해 주세요. 교사로 접속 중인 기기에서는 학생으로 전환한다는 안내와 별도의 입장 버튼이 표시됩니다.

같은 반에서 이미 사용 중인 학생 이름은 입장할 수 없습니다. 동명이인은 번호를 덧붙여 구분하거나 선생님이 이전 입장 기록을 정리해 주세요. 이미 로그인한 같은 휴대폰에서는 기존 조원 기록을 이어 사용합니다. 실제 로그아웃 후 복구는 최신 2026-09-28.5의 선생님 재입장 QR을 이용하세요. [최신 안내](공지푸시-업데이트-안내.md)

## 위치 표시 강조

**우리 조 위치 찍기**를 누르면 확인 창 테두리가 주황빛으로 맥동합니다. 지도에서 지점을 고르면 **여기에 표시** 버튼도 함께 빛납니다. 표시하거나 취소하면 효과가 사라집니다. 휴대폰의 움직임 줄이기 설정에서는 고정된 테두리로 강조합니다.

앱 주소 QR은 앱을 한 번 열어 저장한 뒤 인터넷이 없어도 표시할 수 있습니다. 새 조 초대 발급과 초대로 입장하는 작업에는 인터넷 연결이 필요합니다.
