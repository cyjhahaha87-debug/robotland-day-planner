# 선택해서 말하기

반 채팅 아래 **선택해서 말하기 · Language**에서 사용할 수 있습니다.

1. 한국어, English, 中文, Русский 중 언어를 고릅니다.
2. 상황별로 묶인 드롭다운에서 하고 싶은 말을 고릅니다.
3. 필요한 대상·장소·시간·몸 상태를 선택합니다.
4. 미리보기에서 확인하고 **채팅 입력창에 넣기**를 누릅니다.
5. 기존 입력창에서 더 수정하거나 문장을 추가한 뒤 **보내기**를 누릅니다.

예: 기다리고 있다고 알리기 → 우리 조 → 스카이타워

- 한국어: 우리 조는 스카이타워에서 기다리고 있어요.
- English: We're waiting at Sky Tower.

## 범위와 동작

- 28개 문장 틀: 위치·이동, 놀이기구·대기, 식사·화장실·휴식, 도움·건강, 시간·집합, 짧은 답변.
- 자주 쓰는 장소 6개, 놀이기구 22개, 전시·체험 12개의 선택지.
- 언어를 바꿔도 문장 틀과 선택값은 유지됩니다.
- 외국어를 선택하면 한국어와 해당 언어를 줄바꿈으로 묶습니다. 한국어 선택 시 한 번만 표시합니다.
- 기존 작성 내용 뒤에 덧붙이며, 채팅의 1,000자 한도를 넘으면 삽입하지 않습니다.
- 선택·삽입 단계에서는 전송하지 않습니다. 기존 보내기 버튼과 대화/상황 보고/공지 구분을 사용합니다.
- 인터넷 번역 서비스를 호출하지 않습니다. 앱의 오프라인 캐시에 언어팩을 포함합니다.
- 일반 자유 입력 채팅은 자동 번역하지 않습니다. 앱 전체 언어는 상단 언어 선택에서 바꾸며, 이때 선택형 채팅 언어도 함께 맞춥니다. 이 창에서만 별도 언어를 선택할 수도 있습니다.
- 시설의 외국어 이름은 이해를 돕는 표기입니다. 외국어 장소 목록에는 한국어 이름도 같이 표시합니다.

## 수정할 파일

- public/chat-phrases.js: 공통 문장 ID, 선택 항목, 조합 규칙.
- public/chat-ko.json, chat-en.json, chat-zh.json, chat-ru.json: 같은 ID를 사용하는 언어별 문구.
- public/word-chat.js, word-chat.css: 선택 창과 기존 채팅 입력창 연결.
- tests/word-chat.cjs: 네 언어 조합, 선택 범위, 기존 초안 보존과 길이 제한 검증.

문장에 따라 필요한 항목만 fields에 선언합니다. 대상이 있는 문장은 text 배열의 첫 번째가 '나', 두 번째가 '우리 조'입니다. 장소·시간·상태는 공통 ID를 각 언어팩의 표현으로 바꿉니다. 새 문장을 추가할 때는 네 팩에 같은 ID와 자리표시자를 함께 추가하세요.

화면과 언어팩만 추가한 기능이므로 Apps Script 교체는 필요하지 않습니다. 검증 후 Git에 반영하면 기존 Netlify 배포 경로로 적용됩니다.
