# 2026-09-29 입장 성능·개인 핑·작은 화면 수정

Apps Script 버전: **2026-09-29.2**. 사용자가 기존 웹앱 배포를 갱신했고 공개 상태 주소에서 버전과 `fast-entry`, `entry-retry`, `member-locations`, `concurrent-reads`를 확인했습니다.

## 동시 입장 개선

- 한 요청 안에서 같은 인증값의 해시는 한 번만 계산합니다. 다음 요청에는 재사용하지 않으며 권한과 세션은 매번 확인합니다.
- 입장 때 세션·조 구성원·학생 명단을 한 번씩 읽고 필요한 행만 저장합니다. 이전 명단 보완은 일괄 저장합니다.
- 새 웹에서는 학생 자동 복구 키를 입장 요청에 함께 저장합니다. 별도 복구 등록 요청과 잠금 획득을 줄이며, 조 초대 응답의 조 정보를 화면에 재사용합니다.
- 10분 동안 유효한 임의의 입장 비밀값으로 같은 요청을 재시도할 수 있습니다. 서버가 비밀값·시간·반/초대·이름·기기·복구 키를 묶어 세션 토큰을 생성합니다. 응답을 잃어도 같은 버튼을 다시 누르면 중복 가입 없이 이어집니다. 기기 ID나 이름만으로 기존 학생을 인증하지 않습니다.
- 코드 오입력 제한은 기기별 10회/15분과 IP 전체 100회/15분으로 나눕니다. 기기 ID를 바꾸는 무제한 추측도 막습니다. 검증된 64자리 조 초대 토큰은 짧은 코드의 오입력 제한과 분리합니다.
- 이름 중복 검사와 저장을 보호하는 전역 쓰기 잠금은 유지합니다. 불명확한 통신 실패를 무조건 자동 재전송하지 않습니다.

## 위치 공유

지도에서 직접 위치를 선택하며 GPS를 자동 추적하지 않습니다.

| 핑 | 누가 찍나 | 누가 보나 |
|---|---|---|
| 교사 개인 핑 | 해당 반에 입장한 교사, 조 가입 불필요 | 같은 반 학생과 교사 |
| 학생 개인 핑 | 해당 반 학생, **조 가입 불필요** | 본인·같은 반 교사·현재 같은 조 학생 |
| 기존 조 핑 | 현재 조 구성원 | 같은 반 전체 |

조가 없는 학생끼리는 서로의 개인 핑을 보지 못합니다. 서버에서 현재 조 소속을 확인해 응답을 걸러냅니다. 조 이동·탈퇴·해산은 다음 조회에 반영되며, 다른 반이나 교사 모임의 전체 현황에는 개인 핑을 포함하지 않습니다. 개인 핑은 기기당 하나이고 본인 핑만 지울 수 있습니다. 교사의 기존 조 핑 삭제 권한은 유지합니다.

조·개인 핑은 기존 조 조회와 함께 갱신하므로 개인 핑을 위한 별도 주기 요청을 추가하지 않았습니다. 10분 지난 위치는 오래된 표시, 24시간 지난 위치는 숨김 처리합니다. 개인 핑 작성자의 유효한 해당 반 세션이 없으면 반환하지 않습니다. 학생 삭제 시 개인 핑도 정리합니다.

## 작은 휴대폰의 채팅

- 긴 공지는 한 줄 요약으로 표시하고 누르면 펼칩니다. 펼친 내용에도 높이 제한과 스크롤을 적용합니다.
- 선택형 대화·메시지 종류·상황 보고를 한 줄 도구 모음으로 정리합니다. 옆으로 밀어 나머지 도구를 사용할 수 있습니다.
- 입력창과 보내기 버튼을 한 줄에 두고 입력창은 내용에 따라 최대 두 줄 정도로 늘어납니다.
- 채팅 화면의 상단 메뉴를 줄이고, 채팅을 열 때 마지막 메시지를 보여줍니다.
- 키보드로 사용 가능한 화면이 줄면 입력창이 그 위에 남도록 조정합니다. 짧은 가로 화면에도 대화 영역을 확보했습니다.
