# 공지 알림·학생 재입장 업데이트

공개 앱: https://robotland-trip.netlify.app/

이번 저장소 버전은 **2026-09-28.5**입니다. 공지 알림과 학생 재입장을 함께 포함합니다. 기존 반·조·동선 데이터, 코드, 연결 주소를 유지합니다.

**확인 완료 (2026-09-28):** Apps Script 2026-09-28.5 연결과 사용자 아이폰 시험 알림 수신을 확인했습니다. 현재 사이트는 아래 교체 작업을 이미 마쳤습니다. [집에서 이어서 작업하기](집에서-이어하기.md)

## 이후 Apps Script를 수정했을 때

1. 사용 중인 구글시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. **Code.gs 전체 내용**을 함께 제공한 **RobotlandSheets-공지알림-재입장.gs**의 전체 내용으로 교체하고 저장합니다. 저장소에서는 `integration/RobotlandSheets.gs`가 같은 파일입니다.
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 누릅니다.
4. 로봇랜드 앱을 새로고침합니다. 아이폰에서는 홈 화면에 설치한 앱을 다시 열고, 위쪽 **알림 → 상태 확인**을 누릅니다.

처음 설정을 다시 실행하거나 새 웹앱 주소를 만들 필요가 없습니다. 필요한 시트 탭은 자동으로 만들어집니다. 지금 사용 중인 Netlify 사이트의 푸시 키는 서버에 설정했으며 개인키는 비밀값 보호를 적용했습니다.

## 이미 홈 화면에 설치한 테스트 아이폰

1. 기존 테스트 계정으로 접속한 **홈 화면의 로봇랜드 앱**을 엽니다.
2. 위쪽 **알림 → 공지 알림 받기 → 허용**을 누릅니다.
3. **이 아이폰에 시험 알림**을 누른 뒤 홈 화면으로 나가 화면을 잠급니다.
4. 약 10초 뒤 시험 알림을 확인하고 눌러 앱으로 돌아옵니다. 시험 알림은 해당 기기에만 보냅니다.
5. 실제 공지를 확인하려면 컴퓨터에서 같은 반의 선생님 계정으로 공지를 등록하고 아이폰을 잠가둡니다. 일반 대화·상황 보고에는 푸시가 없습니다.

알림을 거절했다면 아이폰 설정에서 이 앱의 알림을 허용한 뒤 다시 시도하세요. 집중 모드에서는 알림이 조용히 전달되거나 나중에 표시될 수 있습니다. 앱의 ‘푸시 서비스에 전달’ 표시는 실제 잠금 화면 표시나 읽음 확인을 뜻하지 않습니다. 사용자의 실제 아이폰 시험 수신은 확인했으며, 다른 기기에서도 위 순서로 확인할 수 있습니다.

## 학생이 다시 들어오는 방법

- **같은 휴대폰:** 앱을 닫았다 열어도 접속을 확인하고, 세션이 사라졌다면 저장된 기기 인증키로 기존 이름과 조를 복구합니다. 이 과정에서 아이가 코드를 기록하거나 입력하지 않습니다.
- **연결이 느릴 때:** ‘우리 반 연결 중’ 또는 ‘다시 확인’이 표시됩니다. 통신 실패만으로 로그아웃 처리하지 않습니다. 지도와 저장된 개인 계획을 먼저 사용할 수 있습니다.
- **직접 로그아웃·앱 데이터 삭제·휴대폰 변경:** 선생님이 **우리 반 → 조 → 학생 명단 → 재입장 QR**을 누릅니다. 해당 학생만 QR을 찍고 자기 이름이 맞는지 확인한 뒤 **기존 학생으로 재입장**합니다.
- QR은 **10분·1회 사용**입니다. 새 QR을 만들면 이전 QR은 만료됩니다. 재입장하면 이전 기기의 접속·복구키는 무효가 되고 기존 조 소속은 유지됩니다.
- 아이폰 카메라에서 QR을 열면 Safari로 열릴 수 있습니다. **이미 설치된 홈 화면 앱을 계속 쓸 때는**, 선생님에게 링크를 받아 그 앱의 로그인 화면에서 **선생님 재입장 링크 붙여넣기**를 사용하세요.
- 학생이 자기 이름만 입력해 기존 학생을 되찾을 수는 없습니다. 기존 학생을 이름1·이름2로 재가입시키지 마세요. 실제 동명이인은 최초 입장 때 선생님이 번호 등을 붙여 구분해 주세요.
- 선생님의 **인원 삭제**는 접속·조 소속·복구 수단까지 해제합니다. 선생님 본인은 **선생님 로그인 · 재입장 → 교사 입장코드 + 이름**으로 다른 기기에서도 바로 입장합니다. 공용 교사 코드는 교사 모임으로, 반별 선생님 코드는 해당 반으로 연결됩니다. 학생용 QR이 필요하지 않습니다. 같은 기기는 선생님 이름을 기억하며 코드는 저장하지 않습니다.

새 휴대폰에서는 기존 조의 공유 동선을 다시 열 수 있습니다. 이전 휴대폰에만 저장했던 개인 계획은 그 기기 또는 구글시트 백업에서 확인합니다.

## 지도 변경

- **화장실** 토글: 안내도 표지 11곳을 표시합니다. 표지를 누르면 위치 이름을 확인하고, 위치 목록으로 선택하면 확대합니다. 동선에는 추가하지 않습니다. 노란 네모와 아래 이름을 크게 표시하며, 마우스를 올리거나 누를 때 표지가 움직이지 않습니다.
- 점심 집합은 **포크·숟가락 표지가 있는 점심 식당**, **12:00~12:40**입니다. 다목적홀은 일반 전시·체험 시설로 남겨두었습니다.
- 다목적홀로 연결하던 340m·221m는 식당 이동거리로 사용하지 않습니다. 나머지 4개 측정 구간을 기준으로 식당까지의 보행 시간을 추정합니다. 저장된 계획도 새 식당 위치로 다시 계산합니다.
- 퇴장 집합은 그대로 **13:00 로봇 앞 원형 공간**입니다.
- 아이폰 상단 상태 영역·하단 홈 표시줄 여백을 확보하고 주요 버튼을 최소 44px로 배치했습니다.

## 서버 운영 메모

알림은 같은 반의 유효한 세션과 등록된 기기에만 전송합니다. 알림 본문에는 학생 이름이나 공지 전문을 넣지 않습니다. 실패 시 최대 15분 안에서 재시도하고 이미 접수된 기기는 제외합니다. 선생님 화면에 푸시 접수 실패가 표시되면 ‘알림 다시 요청’을 사용할 수 있습니다.

새 사이트에 복제하는 경우 `SHEETS_API_URL`, `SHEETS_BRIDGE_SECRET`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`가 필요합니다. 개인키는 비밀값으로 설정하고 공개 후처리 범위를 제외하세요. 발송 함수의 신뢰 주소도 새 사이트 주소에 맞춰 변경해야 합니다. 키를 공개 파일이나 Git 저장소에 넣지 마세요.
