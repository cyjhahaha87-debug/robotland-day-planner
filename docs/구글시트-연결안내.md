# 로봇랜드 · Apps Script 연결 안내

이 앱은 **휴대폰에 개인 계획을 저장**하고, **Apps Script를 통해 구글시트에 반·조·공유 동선·메시지를 저장**합니다. 별도 구글시트 API 키는 필요하지 않습니다. 현재 Apps Script **2026-09-28.5**가 연결되어 반·조·공지 푸시·학생 복구 기능을 사용할 수 있습니다. 집에서 이어서 작업할 때는 [이 문서](집에서-이어하기.md)를 먼저 보세요.

## 새 프로젝트의 최초 설정

1. [제공한 구글시트](https://docs.google.com/spreadsheets/d/1BPPSKOvkuQarxyLL08L3WL1i5hlqif0ORETJ_Gr2o18/edit)를 엽니다.
2. **확장 프로그램 → Apps Script**에서 [최신 `RobotlandSheets.gs`](../integration/RobotlandSheets.gs) 전체 코드를 붙여 넣고 저장합니다.
3. **setupRobotland** 함수를 실행하고, Google이 요청하는 시트 접근 권한을 승인합니다. 기존 시트를 지우지 않고 필요한 탭을 추가합니다. 현재 운영 중인 저장소를 업데이트할 때는 setup을 다시 실행하지 않아도 필요한 새 탭이 자동 생성됩니다.
4. **배포 → 새 배포 → 웹 앱**에서 실행 사용자를 **나**, 액세스 권한을 **모든 사용자**로 선택합니다. 학교 정책으로 이 옵션이 없다면 학교 관리자에게 확인해야 합니다.
5. **/exec로 끝나는 웹앱 URL**을 복사합니다.
6. 시트를 새로고침한 뒤 **로봇랜드 → 연결 비밀키 확인**에서 연결 비밀키를 확인합니다.
7. 앱 서버에 아래 두 값을 설정하고 다시 게시합니다.

| 서버 설정 | 값 |
|---|---|
| SHEETS_API_URL | Apps Script 웹앱 URL |
| SHEETS_BRIDGE_SECRET | 연결 비밀키 · 비밀 설정으로 등록 |

시트 자체를 학생에게 공개하거나 편집 권한을 줄 필요는 없습니다. 연결 비밀키는 학생에게 배부하지 않습니다. 코드 수정 후에는 Apps Script의 **배포 관리 → 수정 → 새 버전**으로 갱신해야 웹앱에 적용됩니다.

## 선생님이 앱에서 반 만들기

소유자가 시트의 **로봇랜드 → 교사용 개설코드 확인**에서 4자리 코드를 확인해 선생님에게 전달합니다. 선생님은 앱의 **우리 반 → 새 반 만들기**에서 이 코드, 반 이름, 표시 이름을 입력합니다.

생성 후 **학생 참여코드**와 **선생님 재입장 코드**가 별도로 발급됩니다. 둘 다 영문·숫자 4자리입니다. 학생에게는 학생 참여코드만 배부합니다. 세로 화면에서는 **반 설정**을 열면 코드를 확인할 수 있습니다.

코드 기본 유효기간은 30일입니다. AccessCodes 탭의 enabled를 FALSE로 바꾸면 해당 코드의 새 로그인을 막습니다. 학생 접속·복구키·조 소속까지 해제하려면 앱의 교사 **인원 삭제**를 사용합니다. Sessions 행만 삭제하면 기기의 인증키로 복구될 수 있습니다. 세션은 최대 7일 또는 코드 만료일까지 유지됩니다.

## 학생과 조 운영

- 학생은 반 코드와 이름으로 입장합니다.
- **조 · 동선 공유**에서 이름을 정해 조를 만들거나, 같은 반의 조 목록에서 **입장 / 이 조로 이동**을 누릅니다. 조 코드는 입력하지 않습니다.
- 조에서 나가기와 다른 조로 이동은 자유롭습니다. 같은 이름을 써도 다른 반의 조와 섞이지 않습니다.
- 선생님은 같은 반 학생의 조를 강제로 배정·이동하거나 **조 없음**으로 내보낼 수 있습니다. 조 해산과 조별 동선 조회도 가능합니다.
- 교사의 조 변경은 접속 중인 학생 화면에 주기적으로 반영됩니다. 변경 후 이전 조의 저장 권한은 서버에서 즉시 차단됩니다.

## 조 동선 공유

**우리 조 동선 열기**에서 함께 쓸 계획을 편집한 뒤 **조원에게 공유**를 누릅니다. 다른 조원은 **최신 동선 불러오기**로 받습니다. 각 기기의 수정본은 자동으로 공유하지 않습니다. 동시에 수정한 경우 최신 동선을 확인하라는 안내가 나오며, 다른 조원의 변경을 덮어쓰지 않습니다.

**내 동선**은 별도로 휴대폰에 유지됩니다. 기기의 브라우저 저장 공간을 지우거나 시크릿 모드로 사용하면 로컬 계획이 사라질 수 있습니다.

## 현장 일정과 기본값

- 출발: 안내도의 **출입구 화살표 지점인 광장**.
- 점심: **12:00~12:40 포크·숟가락 표지 식당**, 필수 일정.
- 퇴장 집합: **13:00 로봇 앞 원형 공간**, 마지막 필수 일정. 출발 광장과 다른 장소입니다.
- 놀이기구 기본 대기: **10분**.
- 이용시간: 영상 길이가 확인된 14개는 영상 기준으로 분 단위 올림. 나머지 8개는 **영상 미확인 · 임시 3분**으로 표시합니다. 모두 직접 수정할 수 있습니다.
- 이동거리: 제공하신 4구간은 측정값, 나머지는 안내도 보행로를 따른 추정값입니다.

가로 화면은 지도와 동선을 나란히, 세로 화면은 탭으로 사용합니다. 인터넷이 연결된 상태에서 한 번 열어 오프라인 준비가 끝나면 지도와 계획을 계속 사용할 수 있습니다. 메시지와 공유 동선은 인터넷 연결이 필요합니다.

## 공개 접속과 푸시

현재 사이트는 공개 접속으로 전환했습니다. 학생들은 ChatGPT 계정 없이 앱을 열 수 있습니다. 앱의 반 코드는 사이트 공개 여부와 별개로 반 데이터를 보호합니다.

공지 전용 푸시가 구현·연결됐고 사용자의 아이폰 시험 수신을 확인했습니다. 일반 대화와 상황 보고는 앱을 열어 확인합니다. 웹 푸시 자체는 별도 앱스토어 앱 없이도 가능하며, iPhone은 iOS 16.4 이상 홈 화면 웹앱과 알림 허용이 필요합니다. [Apple 안내](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)

실제 학생 수로 로그인·공지·보고·조 공유 시험을 한 뒤 사용하세요. Apps Script에는 실행량 제한이 있습니다. [Google 제한 안내](https://developers.google.com/apps-script/guides/services/quotas) · [웹앱 배포 안내](https://developers.google.com/apps-script/guides/web)
