# 집에서 이어서 작업하기

2026-09-28 기준입니다. 앱과 저장소 연결은 완료됐고, **사용자의 실제 아이폰에서 시험 푸시 알림 수신을 확인했습니다.**

## 바로 열기

- [사용 중인 공개 앱](https://robotland-trip.netlify.app/)
- [GitHub 저장소](https://github.com/cyjhahaha87-debug/robotland-day-planner)
- [관리용 구글시트](https://docs.google.com/spreadsheets/d/1BPPSKOvkuQarxyLL08L3WL1i5hlqif0ORETJ_Gr2o18/edit)

- [최신 Apps Script 전체 코드](../integration/RobotlandSheets.gs)

집에서도 공개 앱은 그대로 사용할 수 있습니다. 새 사이트, 새 시트, 새 반을 만들 필요 없이 기존 교사 코드와 이름으로 입장하세요.

## 현재 상태

| 항목 | 상태 |
|---|---|
| 앱 | `main` 브랜치와 Netlify 자동 배포 연결 완료 |
| Apps Script | `2026-09-28.5` 배포·앱 연결 확인 완료 |
| 푸시 | 발송 함수와 비밀키 설정 완료, 사용자 아이폰 시험 알림 수신 확인 |
| 알림 대상 | 같은 반에서 알림을 켠 기기. 선생님의 **공지**만 발송 |
| 시험 알림 | 버튼을 누른 기기에만 약 10초 뒤 발송 |
| 일반 대화·상황 보고·교사 모임·조 변경 | 푸시 발송 없음 |
| 교사 재입장 | 교사 코드 + 이름. 공용 코드는 교사 모임, 반별 코드는 해당 반 |
| 학생 재입장 | 같은 기기 자동 복구, 데이터 삭제·기기 변경·로그아웃 시 교사의 1회용 QR |
| 식사·집합 | 12:00~12:40 포크·숟가락 표지 식당, 13:00 로봇 앞 원 |
| 화장실 | 위치 전용 11곳, 큰 노란 표지와 ‘화장실’ 이름, 동선에 추가 안 됨 |

화장실 표지 위에 마우스를 올리거나 눌러도 표지와 지도가 튀지 않습니다. 위치 목록에서 화장실을 선택하면 해당 위치를 확대합니다.

## 집 컴퓨터에 소스 받기

Git을 사용한다면 터미널에서 다음을 실행합니다.

```sh
git clone https://github.com/cyjhahaha87-debug/robotland-day-planner.git
cd robotland-day-planner
npm ci
npm run dev
```

Node.js 22 이상이 필요합니다. 브라우저에서 `http://127.0.0.1:4317/`을 열면 지도 화면을 확인할 수 있습니다. Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm` 대신 `npm.cmd`를 사용하세요.

Git을 아직 사용하지 않는다면 저장소의 **Code → Download ZIP**으로 받아 압축을 풀 수 있습니다. 다만 이후 변경을 올릴 때는 Git 연결이 필요합니다.

이미 집에 복제해 둔 저장소라면 저장하지 않은 작업을 먼저 확인하고 `git pull --ff-only`, `npm ci` 순서로 최신 내용을 받습니다.

기본 로컬 실행은 지도와 개인 계획을 확인하는 용도입니다. 반·조·공지·푸시 운영 확인은 위 **공개 앱**에서 합니다. 기존 서버 비밀키를 로컬 실행을 위해 다시 발급할 필요는 없습니다.

## 무엇을 고치면 어디에 배포하나

| 수정한 것 | 적용 방법 |
|---|---|
| 지도·아이콘·화면·브라우저 동작 | Git에 커밋하고 `main`으로 push → Netlify 자동 배포 |
| 서버 연결·공지 발송 함수 | 동일하게 Git push → Netlify 자동 배포 |
| `integration/RobotlandSheets.gs` | Git push **후**, 기존 Apps Script Code.gs도 교체하고 **배포 관리 → 연필 → 새 버전 → 배포** |
| 문서만 | Git push로 저장소에 반영 |

현재 Apps Script는 이미 최신 버전으로 배포했습니다. 앞으로 그 파일을 수정했을 때만 다시 교체합니다. Git에 올리는 것만으로 Google의 Apps Script 코드가 바뀌지는 않습니다.

```sh
npm test
npm run build
git status
git add 수정한파일경로
git commit -m "변경 내용"
git push origin main
```

화면을 수정한 뒤 공개 앱을 새로고침하면 새 버전을 받습니다. 홈 화면 앱을 삭제·재설치하면 기기 저장 계획이나 알림 설정에 영향을 줄 수 있으므로 우선 새로고침으로 확인하세요.

## 운영 설정 보관 위치

Netlify의 환경변수 이름은 `SHEETS_API_URL`, `SHEETS_BRIDGE_SECRET`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`입니다. 이미 설정되어 있으며, 비밀값은 저장소에 포함하지 않았습니다. 기존 푸시 구독을 유지하려면 VAPID 키를 임의로 새로 만들지 마세요.

교사 입장코드는 관리용 구글시트의 **로봇랜드 → 교사용 개설코드 확인**에서 확인합니다. 코드, 비밀키, 실제 학생 데이터는 Git에 올리지 않습니다.

학생의 개인 계획은 휴대폰에, 조 공유 동선·반 대화 등은 구글시트에 저장됩니다. 집 컴퓨터에서 Git 저장소를 받는 것만으로 휴대폰의 개인 계획이 복사되지는 않습니다. 필요한 개인 계획은 앱의 **반 설정 → 구글시트에 백업** 기능으로 관리하세요.

## 다음 확인 항목

- 실제 아이폰 **시험 알림 수신은 확인 완료**. 행사 전에는 같은 반 두 기기에서 선생님 공지를 등록해 함께 수신하는지 확인합니다.
- 다른 반에는 공지·조 정보가 보이지 않는지, 교사의 학생 재입장 QR로 원래 조가 복구되는지 실제 운영 기기로 확인합니다. 모의 검증은 통과했습니다.
- 지도 거리 4구간은 제공된 측정값이며, 새 식당까지의 이동은 추정입니다. 종전 다목적홀 기준 340m·221m는 새 식당에 적용하지 않습니다.
- 영상이 확인되지 않은 놀이기구 8개는 임시 이용시간 3분입니다. [이용시간 근거](놀이기구-시간근거.md)를 보완할 수 있습니다.
