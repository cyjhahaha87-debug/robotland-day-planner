# 로봇랜드 동선 플래너

공식 안내도에서 시설을 선택하고 도보 이동·대기·이용시간을 더해 현장 동선을 계획하는 모바일 웹앱입니다. 가로 화면은 지도와 동선을 나란히 표시하며, 지도·개인 계획은 기기에 저장됩니다.

## 기능

- 놀이기구·전시/체험·식음매장·공연장·쇼핑 표시 토글
- 지도 시설 이름 상시 표시, 이미지 끌기·텍스트 선택 방지, 터치 이동·확대
- 놀이기구 기본 대기 10분, 이용시간 14개 영상 근거와 8개 임시값, 각 항목 수정
- 점심 12:00~12:40 다목적홀, 퇴장 집합 13:00 로봇 앞 원형 공간
- 교사 반 개설, 영문·숫자 4자리 반 코드, 반별 공지·대화·상황 보고
- 같은 반 안에서 조 만들기·입장·이동·나가기, 교사 강제 배정·해산
- 조 동선 공유와 동시 수정 충돌 확인, 개인 동선 별도 저장

## Netlify 배포

Netlify에서 이 저장소의 `main` 브랜치를 연결합니다. `netlify.toml`에서 빌드·공개 폴더·서버 함수 설정을 자동으로 읽습니다.

- 빌드: `node scripts/build-netlify.mjs`
- 공개 폴더: `netlify-dist`
- 서버 함수: `netlify/functions`

[Netlify 배포 안내](docs/Netlify-배포안내.md)를 참고하세요. 사이트 이름은 Netlify 계정 아이디와 별개로 설정할 수 있습니다.

## 구글시트 저장소

Google Apps Script가 구글시트를 읽고 씁니다. 브라우저는 같은 사이트의 `/api/`에만 요청하며, 서버 함수가 비밀키를 붙여 Apps Script와 통신합니다.

1. [Apps Script 코드](integration/RobotlandSheets.gs)를 사용할 구글시트에 붙여 넣습니다.
2. `setupRobotland`를 실행하고 웹앱으로 배포합니다.
3. Netlify 환경변수에 `SHEETS_API_URL`, `SHEETS_BRIDGE_SECRET`을 설정하고 다시 배포합니다.

자세한 절차는 [구글시트 연결 안내](docs/구글시트-연결안내.md)에 있습니다. 비밀키·실제 학생 데이터는 이 저장소에 넣지 않습니다. 구글시트 연결 전에는 지도와 개인 계획을 사용할 수 있고, 반·조 기능은 연결 준비 중으로 표시됩니다.

## 실행과 제한

Node.js 22 이상에서 `npm run dev`로 로컬 앱을 실행합니다. 기본 주소는 `http://127.0.0.1:4317`입니다. 외부 라이브러리 설치 없이 실행할 수 있습니다.

제공된 6개 구간은 실측 거리이며 나머지는 안내도의 보행로에 따른 추정입니다. 영상 길이는 실제 운행시간과 다를 수 있습니다. [이용시간 근거](docs/놀이기구-시간근거.md)를 확인하세요.

반·조 동기화에는 인터넷과 Apps Script 연결이 필요합니다. 화면을 닫은 뒤 받는 푸시 알림은 구현하지 않았습니다. 실제 학생 수로 행사 전 접속·공지·조 공유 시험을 진행하세요. 무료 서비스에는 사용량 제한이 있습니다.

안내도와 원본 이미지의 저작권은 경남 마산로봇랜드에 있습니다. 이 앱은 비공식 현장 계획 도구입니다. [공식 안내도](https://www.robot-land.co.kr/info/guide_map_info.php)
